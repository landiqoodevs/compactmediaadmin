Backend setup required

This dashboard needs a Supabase project. Nothing can be saved or published until it is connected.

  1. Create a free project at supabase.com.
  2. Run supabase/setup.sql in the SQL Editor.
  3. Create the owner user and add it to admins (see README).
  4. Put the project URL and anon key in js/config.js.
